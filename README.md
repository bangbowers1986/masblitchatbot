# 🏯 Mas Blit — Chatbot Budaya Blitar

Chatbot AI berbasis Streamlit & Gemini yang membahas budaya, kuliner, festival, dan sejarah **Kabupaten/Kota Blitar** dengan gaya bahasa **santai, lokal, dan semi-formal-humoris**.

## Fitur
- ✅ RAG lokal (tanpa internet, kecuali API Gemini)
- ✅ Memory percakapan per sesi
- ✅ Rekomendasi konten terkait
- ✅ Gaya bahasa Jawa/Blitar otomatis
- ✅ UI mobile-friendly

## Instalasi Lokal
1. `git clone ...`
2. `pip install -r requirements.txt`
3. Buat `.env` dan isi `GEMINI_API_KEY=...`
4. `streamlit run app.py`

## Deployment
- [x] Streamlit Community Cloud (gratis)
- [ ] Render (backend terpisah — opsional)
